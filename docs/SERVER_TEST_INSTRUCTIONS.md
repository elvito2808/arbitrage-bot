# راهنمای تست اولیهٔ سرور Python

## هدف
این تست فقط بررسی می‌کند که Python روی سرور اجرا می‌شود، چند ماژول استاندارد در دسترس‌اند و برنامه می‌تواند یک فایل موقت بسازد، بخواند و پاک کند.

- هیچ بستهٔ اضافی لازم نیست.
- اسکریپت به اینترنت یا API صرافی‌ها متصل نمی‌شود.
- کلید API، رمز عبور، آدرس کیف پول یا اطلاعات محرمانه را نمی‌خواند.
- فایل‌های پروژه را تغییر نمی‌دهد.
- فایل‌های موقت تست پس از پایان پاک می‌شوند.

## فایل مورد تست
`github_access_test.py`

## روش ۱: دریافت فایل از GitHub و انتقال به سرور
1. این شاخه را باز کنید: https://github.com/elvito2808/arbitrage-bot/tree/test/server-script-v1
2. فایل `github_access_test.py` را باز کنید.
3. گزینهٔ **Raw** را بزنید و فایل را روی رایانه ذخیره کنید.
4. فایل را با ابزار انتقال فایل خود (مثلاً SFTP/WinSCP) به پوشه‌ای جداگانه روی سرور منتقل کنید. بهتر است آن را داخل پوشهٔ فعال ربات قرار ندهید.

## روش ۲: اجرا روی سرور لینوکس
به پوشه‌ای بروید که فایل را در آن قرار داده‌اید و اجرا کنید:

```bash
python3 --version
python3 github_access_test.py
```

اگر فرمان `python3` موجود نبود، بررسی کنید آیا `python` نصب است:

```bash
python --version
python github_access_test.py
```

اسکریپت به Python 3.8 یا جدیدتر نیاز دارد و به نصب پکیج نیاز ندارد.

## اجرا روی Windows Server
در Command Prompt یا PowerShell، به پوشهٔ فایل بروید و اجرا کنید:

```powershell
py --version
py github_access_test.py
```

## خروجی مورد انتظار
در پایان، اگر تست موفق باشد، باید این پیام را ببینید:

```text
RESULT: PASS — basic Python runtime and local file operations work.
```

همچنین باید خطوطی با `PASS` برای import ماژول‌ها و خواندن/نوشتن فایل موقت نمایش داده شوند.

## اگر تست خطا داد
1. کل خروجی ترمینال را از خط اول تا آخر کپی کنید.
2. آن را همین‌جا ارسال کنید.
3. اگر خواستید، سیستم‌عامل سرور و خروجی `python3 --version` یا `py --version` را نیز ارسال کنید.

پیش از ارسال خروجی، اگر اطلاعات محرمانه‌ای را خودتان به ترمینال اضافه کرده‌اید، آن را حذف کنید. این اسکریپت به‌طور عادی نباید هیچ راز یا کلید محرمانه‌ای چاپ کند.

## محدودیت این تست
موفقیت این تست فقط اجرای پایهٔ Python و عملیات فایل محلی را تأیید می‌کند. این تست به معنی تأیید اتصال اینترنت، دسترسی GitHub از سرور، اتصال صرافی‌ها، یا صحت عملکرد ربات آربیتراژ نیست.
