# راهنمای تست نسخهٔ دوم: اتصال HTTPS به GitHub

## نتیجهٔ نسخهٔ اول
نسخهٔ اول با Python 3.10.11 روی Windows 10 با موفقیت اجرا شده است. نسخهٔ دوم همان بررسی‌های پایه را تکرار می‌کند و سپس اتصال HTTPS به وب‌سایت GitHub و یک endpoint عمومی GitHub API را می‌سنجد.

## فایل‌ها
- اسکریپت: `github_access_test.py`
- این راهنما: `docs/SERVER_TEST_INSTRUCTIONS.md`

## چه چیزی آزمایش می‌شود؟
1. نسخهٔ Python و import ماژول‌های استاندارد
2. نوشتن و خواندن فایل موقت
3. درخواست HTTPS به `https://github.com/`
4. درخواست HTTPS به `https://api.github.com/rate_limit`

هیچ رمز عبور یا توکن GitHub استفاده نمی‌شود. اسکریپت به مخزن خصوصی دسترسی نمی‌گیرد، فایل‌های پروژه را تغییر نمی‌دهد و به صرافی یا شبکهٔ رمزارزی وصل نمی‌شود.

## دریافت و اجرا در Windows
1. شاخهٔ نسخهٔ دوم را باز کنید: https://github.com/elvito2808/arbitrage-bot/tree/test/server-script-v2
2. فایل `github_access_test.py` را باز کنید و روی **Raw** کلیک کنید.
3. فایل را با همین نام ذخیره کنید و جایگزین نسخهٔ اول کنید.
4. در Command Prompt یا PowerShell به پوشهٔ فایل بروید و اجرا کنید:

```powershell
py --version
py github_access_test.py
```

برای این تست به نصب پکیج اضافه نیاز نیست.

## خروجی موفق
اگر هر دو درخواست HTTPS موفق باشند، پیام پایانی باید چنین باشد:

```text
RESULT: PASS — Python basics and HTTPS access to GitHub work.
```

## اگر خطا دیدید
کل خروجی را از ابتدا تا انتها ارسال کنید. خطاهایی مانند timeout، خطای TLS/SSL یا خطای اتصال می‌توانند به شبکه، پراکسی، فایروال یا گواهی‌های سیستم مربوط باشند؛ بر اساس خروجی دقیق بررسی می‌کنیم.

**مهم:** توکن، رمز عبور، کلید API یا اطلاعات محرمانه را در خروجی یا پیام خود قرار ندهید. این اسکریپت نباید هیچ‌کدام را درخواست کند یا چاپ کند.

## محدودیت
این تست فقط اتصال HTTPS عمومی به GitHub را بررسی می‌کند. چون از توکن استفاده نمی‌کند، دسترسی احراز هویت‌شده به مخزن خصوصی یا امکان Push از سرور را اثبات نمی‌کند. دسترسی خواندن و نوشتن اتصال GitHub در سمت ChatGPT جداگانه با ایجاد و بازخوانی فایل در یک شاخهٔ آزمایشی تأیید شده است.
